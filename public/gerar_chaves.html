Setup Seguro do Fabricante

Por segurança, a geração de chaves foi removida do navegador. A chave privada agora fica fora do web root e nunca é enviada ao cliente.

  1. Copie .env.example para .env.
  2. Defina TCC_ADMIN_USER, TCC_ADMIN_PASSWORD e TCC_KEY_PASSPHRASE.
  3. No servidor, execute php bin/gerar_chaves.php.
  4. Depois, faça login em login.php para acessar o módulo do fabricante.
As chaves são gravadas em /opt/lampp/storage/tcc/keys por padrão. Use TCC_STORAGE_PATH para alterar o local.
